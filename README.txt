CALCULADORA CONDUCTOR — Android

Esta versión funciona como aplicación web instalable (PWA), sin Internet después de la primera carga.

ARCHIVOS:
- index.html: aplicación
- manifest.webmanifest: configuración instalable
- sw.js: funcionamiento offline

IMPORTANTE:
En Android/Chrome, una PWA normalmente se instala desde una dirección web (https://...). Un archivo ZIP abierto localmente no siempre permite que Chrome active "Instalar aplicación" ni el Service Worker.

Por eso, si solo tienes el teléfono, la forma más sencilla es publicar estos archivos en un hosting estático gratuito y luego abrir el enlace en Chrome y elegir "Agregar a pantalla de inicio" / "Instalar aplicación".

La aplicación no requiere cuenta, ni servidor, ni Internet para sus cálculos una vez instalada/cargada.
